# A common palindromic method architecture

Represent extended methods as explicit symmetric sequences of spatial and time operations. A method should select its palindrome and projection, while a shared implementation handles execution, derivatives, energy and run lifecycle.

This is a separate change from 2026-10-21-uncoupled-bm4. The user accepted the common architecture scope and requested preparation and execution on 2026-10-21. Both BM4 variants remain uncoupled.
