\begin{abstract}
This note combines two constructions. First, a non-autonomous second-order
ABBA step is made implicit by Hairer's symmetric projection on the duplicated
phase space. Second, three complete implicit projected ABBA steps are composed
with the symmetric coefficients $\gamma,\delta,\gamma$ in order to cancel the
complete third-order defect. The resulting ideal method has local truncation
error $\OO(h^5)$ and global order four. Each outer stage has its own multiplier
and signed time interval, so one fourth-order step requires three complete
implicit solves.
\end{abstract}

\section{Implemented configuration space}

\texttt{ABBA4Implicit} is one model with three independent configuration axes:
\begin{center}

\texttt{state\_extension}
 & \texttt{physical}, \texttt{shared\_time}, \texttt{fully\_extended}\\
\bottomrule
\end{tabular}
\end{center}
All three signed substeps use the same selected configuration.  The detailed
derivation below uses the reduced physical Newton branch because it exposes the
smallest exact Jacobian.  The simultaneous formulation has the same ideal root
after block elimination; Broyden approximates the chosen residual Jacobian by
secant updates.  Shared-time mode duplicates only the physical state, whereas
fully extended mode duplicates $Z=(z,t,k)$.  These variants change state and
workspace dimensions but retain the defining policy of one projection after
each of the three signed ABBA maps.

\section{GC2D system and duplicated phase space}
The physical state is
\begin{equation}
    z=(X,Y)\in\RR^2,
\end{equation}
and the non-autonomous guiding-center dynamics is written as
\begin{equation}
    \dot z=f(z,t),
    \qquad
    f(z,t)=J_0\nabla_z\phi(z,t),
    \qquad
    J_0=\begin{pmatrix}0&-1\\1&0\end{pmatrix}.
\end{equation}
Its spatial Jacobian is
\begin{equation}
    W(z,t):=D_zf(z,t)=J_0\nabla_z^2\phi(z,t).
\end{equation}

As in the implicit ABBA construction, duplicate the state:
\begin{equation}
    Y=(u,v)\in\RR^4,
    \qquad u,v\in\RR^2.
\end{equation}
The physical state is represented by the diagonal manifold
\begin{equation}
    \mathcal M=\{(u,v)\in\RR^4:\ u=v\}.
\end{equation}
Introduce
\begin{equation}
    G=\begin{pmatrix}\Id&-\Id\end{pmatrix},
    \qquad
    E=\begin{pmatrix}\Id\\\Id\end{pmatrix},
    \qquad
    N=G^T=\begin{pmatrix}\Id\\-\Id\end{pmatrix}.
\end{equation}
Hence
\begin{equation}
    Ez=(z,z),
    \qquad
    N\mu=(\mu,-\mu),
    \qquad
    GG^T=2\Id.
\end{equation}

\section{The basic non-autonomous ABBA map for an arbitrary signed step}
The key point for the fourth-order composition is that we need the same ABBA routine for an arbitrary \emph{signed} substep length $\ell$. Let the substep start at time $\tau$ and finish at
\begin{equation}
    \tau^+=\tau+\ell.
\end{equation}
Define
\begin{equation}
    s=\frac{\ell}{2}.
\end{equation}
The four explicit duplicated-space stages are
\begin{align}
    u^{(1)}&=u^{(0)}+s f\bigl(v^{(0)},\tau\bigr), \label{eq:A1}\\
    v^{(1)}&=v^{(0)}+s f\bigl(u^{(1)},\tau\bigr), \label{eq:B1}\\
    v^{(2)}&=v^{(1)}+s f\bigl(u^{(1)},\tau^+\bigr), \label{eq:B2}\\
    u^{(2)}&=u^{(1)}+s f\bigl(v^{(2)},\tau^+\bigr). \label{eq:A2}
\end{align}
Thus
\begin{equation}
    \PhiA_{\ell,\tau}
    =A_{s,\tau^+}\circ B_{s,\tau^+}\circ B_{s,\tau}\circ A_{s,\tau}.
\end{equation}
The two endpoint times $\tau$ and $\tau^+$ are essential. In particular, if $\ell<0$, then $\tau^+<\tau$ and the same formulas automatically describe a backward non-autonomous ABBA step.

\section{One complete implicit projected ABBA step}
We now define the actual second-order physical map used inside the new fourth-order method. Given a physical state $z$ at time $\tau$, introduce a multiplier
\begin{equation}
    \mu\in\RR^2
\end{equation}
and pre-correct the duplicated input by
\begin{equation}
    Y^{(0)}(\mu)=Ez+N\mu
    =\begin{pmatrix}z+\mu\\z-\mu\end{pmatrix}.
    \label{eq:precorrection}
\end{equation}
Therefore
\begin{equation}
    u^{(0)}=z+\mu,
    \qquad
    v^{(0)}=z-\mu.
\end{equation}
Apply the four stages \eqref{eq:A1}--\eqref{eq:A2} and denote the auxiliary output by
\begin{equation}
    \widetilde Y^+(\mu)
    =\PhiA_{\ell,\tau}(Ez+N\mu)
    =\begin{pmatrix}u^{(2)}(\mu)\\v^{(2)}(\mu)\end{pmatrix}.
\end{equation}
The same multiplier is then applied at the output:
\begin{equation}
    Y^+(\mu)=\widetilde Y^+(\mu)+N\mu
    =\begin{pmatrix}u^{(2)}(\mu)+\mu\\v^{(2)}(\mu)-\mu\end{pmatrix}.
\end{equation}
We impose $Y^+(\mu)\in\mathcal M$. Since $G$ measures the difference between the two copies, the multiplier is determined by the reduced residual
\begin{equation}
    \boxed{
    R_{\ell,\tau}(z,\mu)
    :=G\PhiA_{\ell,\tau}(Ez+N\mu)+2\mu=0.
    }
    \label{eq:residual}
\end{equation}
Equivalently,
\begin{equation}
    R_{\ell,\tau}(z,\mu)
    =u^{(2)}(z,\mu)-v^{(2)}(z,\mu)+2\mu.
\end{equation}
If $\mu^*$ is the converged root, the physical output is
\begin{equation}
    \boxed{
    \Psitwo_{\ell,\tau}(z)
    =u^{(2)}(\mu^*)+\mu^*
    =v^{(2)}(\mu^*)-\mu^*.
    }
    \label{eq:implicitstep}
\end{equation}
Thus, in this document,
\begin{equation}
    \boxed{S_2(\tau,\ell)\equiv\Psitwo_{\ell,\tau}}
\end{equation}
means one \emph{complete} implicit ABBA step: pre-projection, four ABBA stages, nonlinear multiplier solve, and post-projection.

\section{Exact reduced Jacobian for the multiplier solve}
For a fixed evaluation of the four stages, define
\begin{align}
    W_1&=W\bigl(v^{(0)},\tau\bigr),
    &W_2&=W\bigl(u^{(1)},\tau\bigr),\\
    W_3&=W\bigl(u^{(1)},\tau^+\bigr),
    &W_4&=W\bigl(v^{(2)},\tau^+\bigr),
\end{align}
and
\begin{equation}
    S:=W_2+W_3.
\end{equation}
The exact Jacobian of the duplicated ABBA map is
\begin{equation}
    J_{\ABBA}
    :=D\PhiA_{\ell,\tau}
    =\begin{pmatrix}
        \Id+s^2W_4S & s(W_1+W_4)+s^3W_4SW_1\\
        sS & \Id+s^2SW_1
    \end{pmatrix}.
    \label{eq:JABBA}
\end{equation}
No commutation of the matrices $W_i$ is assumed; the product order in \eqref{eq:JABBA} must be preserved.

Differentiating \eqref{eq:residual} with respect to the multiplier gives
\begin{equation}
    \boxed{
    K_{\ell,\tau}(z,\mu)
    :=D_\mu R_{\ell,\tau}(z,\mu)
    =GJ_{\ABBA}N+2\Id.
    }
    \label{eq:Kcompact}
\end{equation}
Writing the blocks of \eqref{eq:JABBA} explicitly, this becomes
\begin{equation}
\boxed{
\begin{aligned}
K_{\ell,\tau}
={}&4\Id-s(W_1+W_2+W_3+W_4)\\
&+s^2\bigl[W_4(W_2+W_3)+(W_2+W_3)W_1\bigr]\\
&-s^3W_4(W_2+W_3)W_1.
\end{aligned}}
\label{eq:Kexplicit}
\end{equation}
Remember that here
\begin{equation}
    s=\frac{\ell}{2},
\end{equation}
so the same formula is valid for positive and negative outer substeps.

A Newton iteration for the $k$-th implicit ABBA solve is therefore
\begin{equation}
    \boxed{
    \mu^{(j+1)}
    =\mu^{(j)}-
    K_{\ell,\tau}\bigl(z,\mu^{(j)}\bigr)^{-1}
    R_{\ell,\tau}\bigl(z,\mu^{(j)}\bigr).
    }
    \label{eq:newton}
\end{equation}
Because $K\in\RR^{2\times2}$, its inverse can be evaluated explicitly if desired.

\section{Exact Jacobian of one implicit physical substep}
The reduced Jacobian $K=D_\mu R$ is the matrix needed by Newton, but it is not the Jacobian of the physical map $z\mapsto\Psitwo_{\ell,\tau}(z)$. The converged multiplier depends implicitly on $z$.

Write
\begin{equation}
    J_{\ABBA}
    =\begin{pmatrix}\mathsf A&\mathsf B\\\mathsf C&\mathsf D\end{pmatrix},
\end{equation}
where
\begin{align}
    \mathsf A&=\Id+s^2W_4S,\\
    \mathsf B&=s(W_1+W_4)+s^3W_4SW_1,\\
    \mathsf C&=sS,\\
    \mathsf D&=\Id+s^2SW_1.
\end{align}
Besides $K$, define
\begin{equation}
    L:=D_zR=GJ_{\ABBA}E
    =\mathsf A+\mathsf B-\mathsf C-\mathsf D.
\end{equation}
The implicit function theorem gives
\begin{equation}
    D_z\mu^*(z)=-K^{-1}L.
\end{equation}
Define
\begin{equation}
    P:=\mathsf A+\mathsf B,
    \qquad
    Q:=\mathsf A-\mathsf B+\Id.
\end{equation}
Then the exact physical Jacobian of one implicit projected ABBA substep is
\begin{equation}
    \boxed{
    J_{\Psitwo}
    :=D_z\Psitwo_{\ell,\tau}(z)
    =P-QK^{-1}L.
    }
    \label{eq:physicalJ}
\end{equation}
This formula will also give the Jacobian of the final fourth-order method by a simple product of three $2\times2$ matrices.

\section{Fourth-order composition: three complete implicit ABBA solves}
Let
\begin{equation}
    \boxed{
    \gamma=\frac{1}{2-2^{1/3}},
    \qquad
    \delta=-\frac{2^{1/3}}{2-2^{1/3}}.
    }
    \label{eq:coefficients}
\end{equation}
Numerically,
\begin{equation}
    \gamma\approx1.35120719196,
    \qquad
    \delta\approx-1.70241438392.
\end{equation}
They satisfy
\begin{equation}
    2\gamma+\delta=1,
    \qquad
    2\gamma^3+\delta^3=0.
    \label{eq:orderconditions}
\end{equation}

Starting from $(t_n,z_n)$, define the three signed substeps
\begin{equation}
    \ell_1=\gamma h,
    \qquad
    \ell_2=\delta h,
    \qquad
    \ell_3=\gamma h,
\end{equation}
and their starting times
\begin{equation}
    \tau_1=t_n,
    \qquad
    \tau_2=t_n+\gamma h,
    \qquad
    \tau_3=t_n+(\gamma+\delta)h.
\end{equation}
Then the new fourth-order map is
\begin{equation}
    \boxed{
    \Psifour_{h,t_n}
    =\Psitwo_{\ell_3,\tau_3}
     \circ\Psitwo_{\ell_2,\tau_2}
     \circ\Psitwo_{\ell_1,\tau_1}.
    }
    \label{eq:outercomposition}
\end{equation}
Equivalently,
\begin{align}
    z^{[1]}&=\Psitwo_{\gamma h,t_n}(z_n), \label{eq:outer1}\\
    z^{[2]}&=\Psitwo_{\delta h,t_n+\gamma h}(z^{[1]}), \label{eq:outer2}\\
    z_{n+1}&=\Psitwo_{\gamma h,t_n+(\gamma+\delta)h}(z^{[2]}). \label{eq:outer3}
\end{align}
Each line \eqref{eq:outer1}--\eqref{eq:outer3} contains one separate nonlinear multiplier solve.

\subsection*{The three multipliers}
The three roots should be distinguished explicitly:
\begin{align}
R_{\gamma h,t_n}(z_n,\mu_1)&=0,\\
R_{\delta h,t_n+\gamma h}(z^{[1]},\mu_2)&=0,\\
R_{\gamma h,t_n+(\gamma+\delta)h}(z^{[2]},\mu_3)&=0.
\end{align}
Thus a single fourth-order step contains
\begin{equation}
    \boxed{\mu_1,\ \mu_2,\ \mu_3,}
\end{equation}
not one common multiplier. Each multiplier belongs to one complete implicit projected ABBA substep.

\section{Time structure inside the three implicit ABBA substeps}
The non-autonomous endpoint evaluations must be recomputed for every outer substep.

For the first solve,
\begin{equation}
    \tau_1=t_n,
    \qquad
    \tau_1^+=t_n+\gamma h.
\end{equation}
Therefore its internal ABBA pattern is
\begin{equation}
    A_{\gamma h/2,t_n}
    \rightarrow
    B_{\gamma h/2,t_n}
    \rightarrow
    B_{\gamma h/2,t_n+\gamma h}
    \rightarrow
    A_{\gamma h/2,t_n+\gamma h}.
\end{equation}

For the second solve,
\begin{equation}
    \tau_2=t_n+\gamma h,
    \qquad
    \tau_2^+=t_n+(\gamma+\delta)h.
\end{equation}
Since $\delta<0$, the internal half-step is
\begin{equation}
    s_2=\frac{\delta h}{2}<0,
\end{equation}
and this complete ABBA step evolves backward from $\tau_2$ to $\tau_2^+$.

For the third solve,
\begin{equation}
    \tau_3=t_n+(\gamma+\delta)h,
    \qquad
    \tau_3^+=t_n+h.
\end{equation}
Because $2\gamma+\delta=1$, the complete composition ends exactly at
\begin{equation}
    t_{n+1}=t_n+h.
\end{equation}

\section{Detailed implementation algorithm}
One complete fourth-order step can be implemented as follows.

\begin{enumerate}[label=\textbf{\arabic*.},leftmargin=1.0cm,itemsep=0.5em]
    \item Set the outer coefficients $c_1=\gamma$, $c_2=\delta$, $c_3=\gamma$.

    \item Initialize
    \begin{equation}
        z^{[0]}=z_n,
        \qquad
        \tau_1=t_n.
    \end{equation}

    \item For $k=1,2,3$, set
    \begin{equation}
        \ell_k=c_kh,
        \qquad
        s_k=\frac{\ell_k}{2},
        \qquad
        \tau_k^+=\tau_k+\ell_k.
    \end{equation}

    \item For a current Newton iterate $\mu_k^{(j)}$, set
    \begin{equation}
        u^{(0)}=z^{[k-1]}+\mu_k^{(j)},
        \qquad
        v^{(0)}=z^{[k-1]}-\mu_k^{(j)}.
    \end{equation}

    \item Evaluate the four non-autonomous ABBA stages with the signed half-step $s_k$:
    \begin{align*}
        u^{(1)}&=u^{(0)}+s_kf(v^{(0)},\tau_k),\\
        v^{(1)}&=v^{(0)}+s_kf(u^{(1)},\tau_k),\\
        v^{(2)}&=v^{(1)}+s_kf(u^{(1)},\tau_k^+),\\
        u^{(2)}&=u^{(1)}+s_kf(v^{(2)},\tau_k^+).
    \end{align*}

    \item Form the residual
    \begin{equation}
        R_k=u^{(2)}-v^{(2)}+2\mu_k^{(j)}.
    \end{equation}

    \item Evaluate $W_1,W_2,W_3,W_4$ at the four stage points and construct the exact reduced Jacobian $K_k$ from \eqref{eq:Kexplicit}, using $s=s_k$.

    \item Apply the Newton update
    \begin{equation}
        \mu_k^{(j+1)}=\mu_k^{(j)}-K_k^{-1}R_k
    \end{equation}
    until the chosen convergence criterion is satisfied.

    \item With the converged multiplier $\mu_k^*$, recompute or retain the converged stages and set
    \begin{equation}
        z^{[k]}=u^{(2)}+\mu_k^*=v^{(2)}-\mu_k^*.
    \end{equation}

    \item Advance the starting time for the next complete implicit ABBA solve:
    \begin{equation}
        \tau_{k+1}=\tau_k^+.
    \end{equation}
\end{enumerate}
Finally,
\begin{equation}
    \boxed{z_{n+1}=z^{[3]},\qquad t_{n+1}=t_n+h.}
\end{equation}

\section{Why the implicit composition is fourth order}
For the order argument, lift the complete physical second-order step to the extended state $(t,z)$:
\begin{equation}
    \widehat\Psitwo_{\ell}(t,z)
    :=\bigl(t+\ell,\Psitwo_{\ell,t}(z)\bigr).
\end{equation}
If the multiplier equation is solved exactly and the local root is unique, the symmetric projection together with the palindromic non-autonomous ABBA step gives the reversibility relation
\begin{equation}
    \widehat\Psitwo_{-\ell}
    =\left(\widehat\Psitwo_{\ell}\right)^{-1}.
\end{equation}
Hence the logarithm of this complete implicit step has the formal structure
\begin{equation}
    \log\widehat\Psitwo_h
    =h\mathcal F+h^3E_3+h^5E_5+\cdots.
    \label{eq:logS2}
\end{equation}
Here $\mathcal F$ is the vector field of the autonomous extended problem. The element $E_3$ includes every third-order defect of the complete projected non-autonomous method, including terms generated by the explicit time dependence and by the projection.

Now compose three scaled copies:
\begin{equation}
    \widehat\Psifour_h
    =\widehat\Psitwo_{\gamma h}
     \widehat\Psitwo_{\delta h}
     \widehat\Psitwo_{\gamma h}.
\end{equation}
The consistency condition gives
\begin{equation}
    (2\gamma+\delta)h\mathcal F=h\mathcal F,
\end{equation}
and the coefficient of the complete third-order defect is
\begin{equation}
    (2\gamma^3+\delta^3)h^3E_3=0.
\end{equation}
Because the outer composition is again symmetric, even powers are absent from its logarithm. Therefore
\begin{equation}
    \boxed{
    \log\widehat\Psifour_h
    =h\mathcal F+h^5\widetilde E_5+\OO(h^7).
    }
\end{equation}
Thus
\begin{equation}
    \boxed{\text{local truncation error}=\OO(h^5),}
\end{equation}
and over a fixed time interval
\begin{equation}
    \boxed{\text{global error}=\OO(h^4).}
\end{equation}
The method is therefore fourth order. It is not a fifth-order symmetric method; a consistent symmetric one-step method has even global order.

\section{Symmetry and symplecticity of the complete fourth-order map}
For one complete projected ABBA step, exact solution of the multiplier equation gives
\begin{equation}
    \Psitwo_{-\ell,\tau+\ell}
    \circ
    \Psitwo_{\ell,\tau}
    =I.
\end{equation}
The reverse multiplier is $-\mu$. Since the outer coefficient sequence $(\gamma,\delta,\gamma)$ is palindromic, the fourth-order composition also satisfies
\begin{equation}
    \Psifour_{-h,t_n+h}
    =\left(\Psifour_{h,t_n}\right)^{-1}.
\end{equation}

Under the local hypotheses used for the implicit projected ABBA method---in particular, local uniqueness of the root, invertibility of $K$, and exact solution of the projection equation---each physical second-order map is symplectic:
\begin{equation}
    \left(D\Psitwo_{\ell,\tau}\right)^TJ_0
    D\Psitwo_{\ell,\tau}
    =J_0.
\end{equation}
A composition of symplectic maps is symplectic, hence
\begin{equation}
    \boxed{
    \left(D\Psifour_{h,t_n}\right)^TJ_0
    D\Psifour_{h,t_n}
    =J_0.
    }
\end{equation}
In two physical dimensions this is equivalent to
\begin{equation}
    \det D\Psifour_{h,t_n}=1.
\end{equation}

\section{Jacobian of the fourth-order implicit physical step}
Let
\begin{align}
    J_1&=D\Psitwo_{\gamma h,t_n}(z_n),\\
    J_2&=D\Psitwo_{\delta h,t_n+\gamma h}(z^{[1]}),\\
    J_3&=D\Psitwo_{\gamma h,t_n+(\gamma+\delta)h}(z^{[2]}),
\end{align}
where each $J_k$ is computed from the explicit implicit-step formula \eqref{eq:physicalJ} with its own stage matrices and its own multiplier $\mu_k^*$. The chain rule then gives
\begin{equation}
    \boxed{
    D\Psifour_{h,t_n}(z_n)=J_3J_2J_1.
    }
    \label{eq:totalJ}
\end{equation}
This gives an explicit route to the Jacobian of the new fourth-order physical method without differentiating the nonlinear solver iterations themselves: one differentiates the converged implicit map through the implicit function theorem at each of the three outer stages.

\section{Practical remarks on the nonlinear solves}
\begin{itemize}[leftmargin=0.7cm]
    \item The three multipliers $\mu_1,\mu_2,\mu_3$ solve three different residual equations. They should not be identified with one another.

    \item The middle solve uses $\ell_2=\delta h<0$. Nothing in the residual or Jacobian formulas has to be changed beyond using the signed value $s_2=\delta h/2$ and the corresponding endpoint times.

    \item The formal symmetry and symplecticity statements refer to the exact root of each reduced nonlinear system. With a finite stopping tolerance, these properties are preserved only up to the nonlinear-solve defect.

    \item To observe the designed fourth-order convergence in practice, the error introduced by the multiplier solves should be smaller than the $\OO(h^5)$ local discretization error over the step sizes being tested. A fixed very tight tolerance is often sufficient until the integration error reaches the tolerance floor.

    \item Newton can use the exact $2\times2$ matrix $K$ in \eqref{eq:Kexplicit}. A quasi-Newton method such as Broyden may instead approximate this same reduced Jacobian, without changing the definition of the implicit numerical map when the residual is solved to convergence.
\end{itemize}

\section{Compact schematic view}
The complete construction is
\begin{equation}
\boxed{
\begin{aligned}
&z_n
\\[-1mm]
&\xrightarrow[\mu_1]{\ \text{implicit projected ABBA }(\gamma h)\ }
 z^{[1]}
\\[-1mm]
&\xrightarrow[\mu_2]{\ \text{implicit projected ABBA }(\delta h)\ }
 z^{[2]}
\\[-1mm]
&\xrightarrow[\mu_3]{\ \text{implicit projected ABBA }(\gamma h)\ }
 z_{n+1}.
\end{aligned}}
\end{equation}
Inside every arrow one solves
\begin{equation}
    R_{\ell,\tau}(z,\mu)
    =G\PhiA_{\ell,\tau}(Ez+N\mu)+2\mu=0,
\end{equation}
with
\begin{equation}
    D_\mu R=K
    =GJ_{\ABBA}N+2\Id,
\end{equation}
and then returns
\begin{equation}
    z^+=u^{(2)}+\mu=v^{(2)}-\mu.
\end{equation}
The outer coefficients satisfy
\begin{equation}
    2\gamma+\delta=1,
    \qquad
    2\gamma^3+\delta^3=0,
\end{equation}
so the complete method has local error $\OO(h^5)$ and global order four while retaining the symmetry and symplectic structure of the exact projected substeps.

\section{Summary}
The new method should not be interpreted as three explicit ABBA maps followed by one projection. Rather, it is the composition of three \emph{complete implicit projected ABBA maps}:
\begin{equation}
    \boxed{
    \Psifour_{h,t_n}
    =
    \underbrace{\Psitwo_{\gamma h,t_n}}_{\text{implicit solve for }\mu_1}
    \;\underbrace{\Psitwo_{\delta h,t_n+\gamma h}}_{\text{implicit solve for }\mu_2}
    \;\underbrace{\Psitwo_{\gamma h,t_n+(\gamma+\delta)h}}_{\text{implicit solve for }\mu_3},
    }
\end{equation}
where composition is understood in the usual right-to-left sense.

Every second-order map uses the same reduced implicit architecture as the original projected ABBA method, with the only changes being its signed step length and its two local endpoint times. This preserves the non-autonomous time symmetry at the inner level and enables the outer symmetric composition to cancel the complete third-order defect.
