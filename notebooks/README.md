# Thesis notebooks by section

The numerical prefixes follow the current Spanish thesis chapter: `04_08` means section 4.8, while `04_01_01` means subsection 4.1.1. Paired studies carry the prefix on their folder and retain `01_compute.ipynb` and `02_visualize.ipynb` inside it.

| Section | Notebook or study folder |
| --- | --- |
| 4.1.1 — Particle datasets | [04_01_01_particle_sets_potential.ipynb](04_01_01_particle_sets_potential.ipynb), [04_01_01_third_set_poincare.ipynb](04_01_01_third_set_poincare.ipynb) |
| 4.2 — NumPy/SciPy and JAX | [04_02_bm4_numpy_jax](04_02_bm4_numpy_jax/) |
| 4.3 — Computational cost | [04_03_method_timings](04_03_method_timings/) |
| 4.8 — Accumulated geometric defects | [04_08_midpoint_geometry](04_08_midpoint_geometry/) |

The [thesis index](../../TFM_redaccion/README.md#cuadernos-ordenados-por-apartado) also lists the energy-balance, projection and trajectory-similarity notebooks maintained with the thesis. Python module names, study prefixes, run identifiers and scientific archive paths are independent of notebook numbering. Historical notebooks inside archived campaigns retain their original names and provenance.
