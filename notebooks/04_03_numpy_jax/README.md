## Visualization

[visualisation.py](visualisation.py) is the standalone percent-format source. [prepare_public_data.py](prepare_public_data.py) verifies the 18 original trajectory manifests and prepares `study.json`, `timings.json`, `particles.json`, `trajectories.npz` and their public manifest. All original saved positions and times are retained, so the notebook recomputes distances from trajectories. It verifies the 72 timing records, alternating order and cold/warm compilation records. The later repetitions' trajectories were not saved; their original bitwise determinism check is recorded provenance.

From the code repository, rebuild with `python3 notebooks/04_03_numpy_jax/build_visualisation.py`. Run the focused tests with `.venv/bin/python notebooks/04_03_numpy_jax/test_visualisation.py`. Execute using an offline bundle with `.venv/bin/python notebooks/04_03_numpy_jax/validate_visualisation.py /path/to/bundle --save-outputs`, or using public HTTPS with `--live --save-outputs` instead of the bundle path. The validation metadata states which mode actually ran; local execution is not an actual Colab runtime test. Optional figure export is disabled by default and saves only to a selected runtime directory.

The public visualization bundle was verified through anonymous HTTPS on 2026-11-27. All six notebook code cells completed locally using the unchanged public downloader; all file sizes and SHA-256 digests, 72 timings and 18 trajectories passed validation. The notebook stores both figures and records `execution_mode=public_https`. This proves local Python execution with public B2 data, not execution inside a Google Colab runtime.
